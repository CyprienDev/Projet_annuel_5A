# Projet annuel

Projet annuel réalisé dans le cadre de la cinquième année de Master en Architecture Logicielle.

Le projet est actuellement dans sa phase d'initialisation.
Les besoins fonctionnels, le sujet ainsi que le périmètre de l'application seront définis ultérieurement.

Ce dépôt est préparé en amont afin de disposer d'une base propre pour :

* le développement de l'application ;
* la conteneurisation ;
* l'infrastructure cloud ;
* l'Infrastructure as Code ;
* les pipelines CI/CD ;
* les déploiements automatisés ;
* la gestion de plusieurs environnements ;
* la supervision et l'observabilité ;
* la documentation technique et architecturale.

## Structure du dépôt

```text
.
├── app/
├── infrastructure/
├── docker/
├── .github/
│   └── workflows/
├── scripts/
├── docs/
└── README.md
```

Cette structure pourra évoluer lorsque le sujet, les besoins fonctionnels et l'architecture technique du projet seront définis.
